Build notes
  1. True aspect-ratio:1.586. Colourway is generated from the issuer id, not hand-assigned — new issuers must work automatically.
  2. A card with no last-4 shows “Add last 4” as an affordance, never “unavailable” as an error.

  4. Benefit count on the face is the honest hook — including “No benefits recorded”, which is a content gap, not a failure.
  5. Filters are real controls in the main toolbar, never behind a mode toggle.

Build notes
  1. Category groups, never one flat alphabetical list. Owned cards lead every group.
  2. Three states only — Verified / Check before use / Sources differ. Never the word “Activated”.
  3. The headline value is chosen by a per-category priority, never sorted(allowance)[0]. Lounge leads with visits, rewards with the rate, fees with the amount.
  4. Decimals survive: 5%, 0.5 airmiles, $3.25 — never 0 5.
  5. Unknowns are stated as unknown (“Guest access is not recorded”), never omitted or guessed.

Build notes
  1. One index spans owned and catalog. The scope toggle is always visible, never behind contributor mode.

Build notes
  1. No default credential ships in the repository. A fresh clone has none; the user creates theirs on first reveal.
  2. PIN minimum 6 digits. Argon2id at high cost, escalating delay and lockout on repeated failure.
  3. Copy writes to the clipboard and auto-clears, with the countdown visible. Fields re-hide on a timer and on tab blur.
  4. Changing the code requires the current one. Plaintext never touches a log, a tracked file, or a prompt.
  5. This modal is the only credential surface in the product. There is no lock/unlock state anywhere else.

Seven things that must never come back

Each of these was verified in the previous build. They are the reason it lost trust, and they are all easy to recreate by accident.
